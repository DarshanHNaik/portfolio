The extension that changed my editing experience the most was Prettier, because it fixed messy indentation and spacing automatically with a single Format Document command. Python and Java also made coding easier by adding syntax highlighting, IntelliSense and Run buttons, but these only help with specific languages. Python, Java and Prettier are about the code itself, covering correctness and formatting, while GitLens and Live Share are about history and collaboration. GitLens showed who changed each line and when, and Live Share let me and my partner edit the same file together. I would keep Prettier and GitLens enabled for every project, and enable Python and Java only when working in those languages. Compared with screen sharing, Live Share felt much more like real pair programming, because we each had our own cursor and could type at the same time instead of one person controlling the screen.
